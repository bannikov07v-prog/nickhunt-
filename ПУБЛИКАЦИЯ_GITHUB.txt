NickHunt — готово к публикации на GitHub Pages

1. Перейдите в https://github.com/new и создайте публичный репозиторий с именем nickhunt (можно другое). Для удобства включите «Add a README file».
2. На странице репозитория откройте Add file → Upload files.
3. Распакуйте этот ZIP на телефон/ПК, выделите все файлы внутри, кроме этой инструкции (её тоже можно загрузить), и загрузите их в КОРЕНЬ репозитория. Важно: файл index.html должен быть в корне, а не во вложенной папке.
4. Подтвердите Commit changes (или Propose changes).
5. Репозиторий → Settings → Pages → Build and deployment → Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
6. После публикации адрес обычно будет вида https://ВАШ-ЛОГИН.github.io/nickhunt/ (точный адрес покажут настройки Pages).
7. На iPhone откройте опубликованный URL в Safari → «Поделиться» → «На экран Домой» → «Добавить». Теперь можно запускать NickHunt одним касанием.
8. На Android откройте адрес в Chrome → меню → «Установить приложение» (или «Добавить на главный экран»).

Проверка юзов использует внешний сервис, может возвращать неизвестный статус. Она не заменяет проверку в настройках Telegram. Не предоставляйте пароль Telegram этому приложению.
